# Showstopper Edition — คู่มือฟีเจอร์และวิธีทดสอบ

ทุกอย่างในนี้เป็น "ส่วนตกแต่ง" เท่านั้น: ทำงานจากเหตุการณ์ที่ส่งออกมา **หลัง** บันทึก / Export สำเร็จแล้ว
(`src/lib/fxBus.js`) จึงไม่ยุ่งกับการคำนวณสต็อก, FIFO, LOG, QR, นำเข้า/ส่งออก หรือ Supabase

## 1. ตัวควบคุมความอลังการ & เสียง (ตั้งค่า → ความอลังการ & เสียง)

| ระดับ | ได้อะไร |
|---|---|
| Lite · เรียบง่าย | สีธีม + ฉากนิ่ง ไม่มีอนุภาค ม่านต้อนรับแบบเรียบ |
| Balanced · สมดุล | ตกแต่งแบบเดิม แอนิเมชันเบา ๆ |
| **Grand · อลังการ (ค่าเริ่มต้น)** | ม่านเปิดเทศกาล, parallax มิติลึก, แสงขอบการ์ด, ลำแสงหน้า Login |
| Showstopper · จัดเต็ม | + อนุภาคหนาแน่น 2 ชั้น, ลำแสงสปอตไลต์บนหน้าแรก, ม่านเปิดยาวขึ้น |

- **ลดแอนิเมชัน**: หยุดการเคลื่อนไหวทั้งหมด (ใช้กฎชุดเดียวกับ `prefers-reduced-motion` ของเครื่อง ซึ่งระบบเคารพอยู่แล้ว)
- **เสียงเอฟเฟกต์**: ปิดไว้เป็นค่าเริ่มต้น เป็นเสียงสังเคราะห์ด้วย Web Audio API (ไม่มีไฟล์เสียง) มีปรับความดัง + ปุ่มทดลองเสียง
- **ปุ่มลำโพง** (แถบบน / แถบข้าง) เปิด-ปิดเสียงได้ใน 1 คลิก
- ค่าทั้งหมดเก็บต่อเครื่อง (`localStorage: sts-spectacle`)

**ทดสอบ:** เปลี่ยนระดับ → `<html data-spectacle="…">` เปลี่ยนทันที · เปิด "ลดแอนิเมชัน" → ทุกอย่างหยุด ·
เปิดเสียงแล้วบันทึกรับสินค้า → ได้ยินเสียงกริ๊ง · ปิดด้วยปุ่มลำโพง → เงียบ

## 2. น้องสัตว์เลี้ยงมีชีวิต (`PetCompanion.jsx`, `usePetStore.js`)

| เหตุการณ์จริง | น้องทำอะไร | เสียง (ถ้าเปิด) |
|---|---|---|
| บันทึกรับสินค้า / เพิ่มสินค้า | กระโดดดีใจ + ประกาย 📦✨ + ข้อความตามบริบท | กริ๊ง 4 โน้ต |
| บันทึกจ่ายสินค้า | ท่าตื่นตัว + เครื่องหมาย ❗ + 🔍 | ติ๊ก-ต็อก |
| สต็อกใกล้หมด (วันละครั้ง) | ท่าตื่นตัว + ข้อความเตือน | ติ๊ด ๆ เบา ๆ |
| เปิดรายงาน | ถือเอกสาร 📑 "เตรียมเอกสารให้แล้ว" | — |
| Export PDF / Excel | ปั๊มตรา ✅ "ปั๊ม! เอกสารพร้อมแล้ว" | ตึ้ง |
| ทำรายการต่อกันภายใน 90 วินาที | ป้าย **คอมโบ ×n ⚡** (×5 ปลดล็อก "เต้นฉลองคอมโบ 💃") | เสียงสูงขึ้นตามคอมโบ |

**ท่าลับ:** กดที่น้องรัว ๆ (แต่ละครั้งห่างไม่เกิน 1 วินาที) 5 ครั้ง = หมุนติ้ว 🌀 · 9 ครั้ง = ร่างทองคำ 👑 (8 วินาที)
ดูท่าที่ปลดล็อกแล้วได้ในแผงของน้อง (ส่วน "ท่าลับ") · หลัง 19:00 น้องงีบ งานที่ผู้ใช้ทำจะปลุกน้อง

**หน้า Login:** แมว "มณีสยาม" ทักทาย "สวัสดีครับ 👋" + โบกมือเป็นระยะ, ลำแสงสปอตไลต์หลังการ์ด, แสงวิ่งผ่านการ์ดหนึ่งครั้ง
(ยังปิดตาตอนพิมพ์รหัสผ่านเหมือนเดิม)

**ทดสอบ:** บันทึกรับ 1 รายการ → น้องฉลอง · บันทึกจ่ายต่อทันที → ❗ + "คอมโบ ×2" · เปิดรายงาน → ถือเอกสาร ·
กด Export → ปั๊มตรา · กดที่น้องรัว ๆ 5 ครั้ง → หมุน

## 3. โลกเทศกาล (`FestivalDecor.jsx`, `FestivalLayer.jsx`, `FestivalWelcome.jsx`)

- **Grand Entrance** หลังเข้าสู่ระบบ: ม่านแหวก → ลำแสงสปอตไลต์ → ตราเทศกาลเด้ง → ชื่อเทศกาลไล่ทีละตัวอักษร
  (แยกตามกลุ่มอักษรไทย ไม่ทำให้สระ/วรรณยุกต์หลุด) → คำอวยพร + อนุภาคประจำเทศกาล
  ปุ่ม **"ข้าม · เข้าสู่ระบบทันที"** ใช้ได้ตั้งแต่เฟรมแรก (และ Esc / คลิกด้านนอก)
- **มิติหลายชั้น + parallax:** ท้องฟ้า · อนุภาค · ภูเขาไกล · ฉาก · ละอองใกล้ เลื่อนต่างกันตามเมาส์เล็กน้อย
  (สูงสุด ~20px, นุ่มนวล) เฉพาะระดับ Grand ขึ้นไป บนคอมพิวเตอร์ที่ใช้เมาส์ และไม่ทำงานเมื่อลดแอนิเมชัน
- **ของในฉากโต้ตอบได้:** ชี้ = เรืองแสง, คลิก = ดุ๊กดิ๊ก + เอฟเฟกต์เดิมของแต่ละเทศกาล
- **ความลับ:** ⭐ ดาวเล็ก ๆ ซ่อนอยู่ในฉากด้านล่าง (คลิกแล้วได้คำอวยพรลับประจำเทศกาล) ·
  คลิกฉากด้านล่างเร็ว ๆ 7 ครั้งภายใน 4 วินาที = **โหมดฉลองเต็มพิกัด**
- โค้ดตกแต่งแยกไฟล์ โหลดหลังหน้าเว็บพร้อมแล้วเท่านั้น

**ทดสอบ:** ออกจากระบบแล้วเข้าใหม่ (ช่วงที่มีเทศกาล หรือแอดมินเลือกธีม) → ดูม่าน แล้วกด "ข้าม" ·
เลื่อนลงล่างสุด → หาดาว ⭐ · คลิกฉาก 7 ครั้งเร็ว ๆ

## 4. บรรยากาศตามข้อมูลจริง (`Dashboard.jsx`, `TodaySummary.jsx`, `NavCard.jsx`)

- แสงพื้นหลังหน้าแรกเปลี่ยนตามความเคลื่อนไหววันนี้: เงียบ = ฟ้า, มีรายการ = เขียว, ≥ 10 รายการ = เขียว+ทอง,
  มีสินค้าใกล้หมด = แสงอำพันอ่อน ๆ (ตัวเลขยังอ่านชัด)
- "ชีพจรคลัง" ใต้การ์ดสรุปวันนี้ · การ์ดที่มีรายการวันนี้มีขอบเรืองเขียว · การ์ดสินค้าใกล้หมดเต้นเป็นจังหวะสีอำพัน
- ตัวเลขนับขึ้น (animated counters) — โปรแกรมอ่านหน้าจอได้ยินเฉพาะค่าสุดท้าย
- ป้ายบนการ์ดเมนู: "วันนี้ N รายการ" (Stock In / Out) และ "⚠ ใกล้หมด N" (Stock)
- ขอบการ์ดเป็นแสงไล่สีตอนชี้ (rim light), รูปประกอบขยับตอนชี้ (ล้อรถหมุน กล่องกระโดด ดินสอเขียน ประตูเปิด)

## 5. รายงาน (`Reports.jsx`)

- **Grand Spotlight Header** "ศูนย์รายงานสต็อก" พร้อมลำแสงและตัวเลขปีนี้ (นับขึ้น)
- แถบ **ภาพรวมช่วงที่เลือก** เหนือรายงาน: มูลค่ายอดยกมา / รับ / จ่าย / คงเหลือ + กราฟแท่งรับ-จ่าย
  เปลี่ยนปี/ช่วงแล้วมีแสงกวาดผ่าน · **อยู่นอกส่วนที่ถูกจับภาพเป็น PDF** ไฟล์ PDF จึงไม่มีแถบนี้
